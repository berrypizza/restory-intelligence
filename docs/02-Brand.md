# About

Manifesto는

왜 존재하는가를 정의한다.

Principles는

어떻게 행동하는가를 정의한다.

Brand는

세상을 어떻게 바라보는가를 정의한다.

브랜드는

로고가 아니다.

브랜드는

같은 상황을 다르게 해석하는 능력이다.

---

# 우리는 무엇을 보는가

다른 사람은

가구를 본다.

RESTORY는

사람을 본다.

우리는

상부장을 보면

불안을 본다.

문짝을 보면

오래된 공간을 본다.

의자를 보면

망설임을 본다.

소파를 보면

아쉬움을 본다.

우리는

가구를 수리하지 않는다.

사람의 고민을 해결한다.

---

# 우리는 무엇을 파는가

우리는

상부장 수리를 팔지 않는다.

안심을 만든다.

우리는

문짝 교체를 팔지 않는다.

공간의 변화를 만든다.

우리는

의자 천갈이를 팔지 않는다.

다시 사용할 수 있는 가치를 만든다.

우리는

소파 복원을 팔지 않는다.

후회하지 않는 선택을 만든다.

---

# 우리는 무엇과 경쟁하는가

우리의 경쟁상대는

다른 수리 회사가 아니다.

"고장 나면 새로 사야지."

라는 생각이다.

"설마 괜찮겠지."

라는 방심이다.

"이 정도는 그냥 쓰자."

라는 미루는 습관이다.

RESTORY는

이 생각들과 경쟁한다.

---

# 우리가 만드는 경험

좋은 브랜드는

수리가 끝난 순간 끝나지 않는다.

고객이

"왜 그런지 이해했다."

라고 말하는 순간

브랜드가 시작된다.

우리는

결과보다

이해를 남긴다.

---

# 우리가 사용하는 언어

우리는

겁주지 않는다.

과장하지 않는다.

어렵게 말하지 않는다.

기술을 자랑하지 않는다.

고객이 이해하는 말만 사용한다.

---

# 우리가 하지 않는 것

우리는

없는 문제를 만들지 않는다.

필요 없는 교체를 권하지 않는다.

사진도 보기 전에

가능하다고 말하지 않는다.

원인을 확인하기 전에

해결책을 말하지 않는다.

브랜드는

신뢰를 잃는 순간

끝난다고 믿는다.

---

# 우리가 중요하게 생각하는 것

우리는

한 번의 문의보다

한 사람의 신뢰를 선택한다.

한 번의 판매보다

오래 기억되는 브랜드를 선택한다.

조회수보다

공유되는 경험을 만든다.
