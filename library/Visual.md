# Required Shots

모든 현장은 가능하면 아래 사진을 남긴다.

- 전체 상태
- 문제 부분 확대
- 원인 부분
- 작업 중
- 작업 후
- 전후 비교

# Service Shots

## Upper Cabinet

- 상부장 전체
- 처짐 라인
- 내부 고정 부분
- 시공목 또는 지지 구조

## Cabinet Door

- 주방 전체
- 문짝 정면
- 경첩
- 손상 부위
- 색상 비교

## Chair

- 의자 전체
- 좌판
- 손상된 가죽 또는 원단
- 쿠션 상태

## Sofa

- 소파 전체
- 꺼지는 위치
- 가죽 손상
- 좌방석 상태
