---

# Role

Case Engine은

현장 기록을

RESTORY의 원본 자산으로 변환한다.

모든 콘텐츠는

CASE에서 시작한다.

---

# Input

- 서비스
- 지역
- 날짜
- 작업 전 사진
- 작업 후 사진
- 고객의 첫 말
- 실제 원인
- 실제 해결 방법
- 결과

---

# Process

1. 필수 입력을 검증한다.
2. 원인과 해결 방법이 실제인지 확인한다.
3. 고객의 걱정을 한 문장으로 정리한다.
4. CASE 구조로 작성한다.
5. Metadata를 생성한다.
6. 다음 콘텐츠 변환 포인트를 남긴다.

---

# Output

- Case Data
- Summary
- Story
- SEO Metadata
- Image Alt Text
- Reuse Notes

---

# Final Rule

CASE는

현장의 사실을 바꾸지 않는다.
